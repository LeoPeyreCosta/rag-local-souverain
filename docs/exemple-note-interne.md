# Note interne — Procédures du rayon vrac (exemple)

Ce document est un **exemple** pour tester le RAG local. Remplace-le par tes vrais documents.

## Rupture de stock
En cas de rupture sur un produit vrac, le responsable de rayon passe une commande
d'urgence au fournisseur référencé, signale l'indisponibilité par une étiquette
« temporairement indisponible », et note la rupture dans le cahier de suivi.

## Nettoyage des silos
Les silos vrac sont nettoyés une fois par semaine, le lundi avant l'ouverture.
Chaque silo est vidé, aspiré, puis essuyé avec un chiffon sec. L'eau est interdite
à l'intérieur des silos pour éviter l'humidité.

## Étiquetage des prix
Chaque silo porte une étiquette avec le nom du produit, le prix au kilo, l'origine
et la liste des allergènes. Les étiquettes sont vérifiées lors du réassort.

## Contact fournisseur
Pour les produits secs, le fournisseur principal est livré le mardi et le vendredi.
Les commandes doivent être passées avant 16 h la veille.
